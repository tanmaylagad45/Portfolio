## 🛠️ Technology Stack

- **Core**: React 19, TypeScript
- **3D Graphics & Shaders**: Three.js, Canvas WebGL2
- **Styling**: Tailwind CSS v4, Glassmorphism, CSS Cyber-Grid
- **Icons**: Lucide Icons & Custom SVG Brand Badges
- **FX**: Web Audio API Sound Synthesizer, Canvas Confetti

## 📦 Getting Started

### Development
```bash
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
npm run preview
```

## 🔧 Easy Customization

All personal information, links, projects, and skills are decoupled into a single configuration file:
👉 **`src/data/portfolioData.ts`**

To update your projects, skills, or resume details in the future, simply edit `portfolioData.ts`!
